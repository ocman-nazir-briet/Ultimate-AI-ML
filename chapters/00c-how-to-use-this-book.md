# How to Use This Book

Throughout the book, **flow diagrams** depict processes and architectures, **figures** plot the concepts being discussed, **tables** compare algorithms side by side, and **code blocks** provide runnable examples. Each chapter closes with a **Summary** of key takeaways and a set of **Exercises** to test and extend your understanding.

All code examples use **Python**, the lingua franca of machine learning. Classical machine learning examples use **scikit-learn**, **NumPy**, and **pandas**. Deep learning examples are provided in **both TensorFlow/Keras and PyTorch**, so you can follow along with whichever framework you prefer. Examples favor built-in or synthetically generated datasets so they run without external downloads.

To get the most from the book, read with an editor open: type the examples, change them, and observe what happens. The exercises at the end of each chapter are designed to be done, not merely read.
